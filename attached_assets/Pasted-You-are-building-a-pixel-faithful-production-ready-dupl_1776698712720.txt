3. Visual fidelity requirements
The duplicate must look indistinguishable from the Wix original to a non-technical viewer. To achieve this:
	1.	Scrape the live site first. For every route above, fetch the rendered HTML, pull down every referenced image, icon, and font file, and save them to /public/assets/scraped/ organized by route. Use a headless browser (Playwright) so JS-rendered content is captured.
	2.	Extract the design tokens. Parse the computed styles from the homepage, services pages, and a blog post. Produce a design-tokens.json that captures:
	•	Full color palette (primary, secondary, accents, neutrals, gradient stops — the site uses a “Nebula Gradient” and North Star / night-sky visual language, capture those exactly)
	•	Typography scale (font families, weights, sizes, line heights, letter spacing for h1–h6, body, small, caption, button)
	•	Spacing scale
	•	Border radii, shadows, and any blur/backdrop-filter values
	•	Breakpoints
	3.	Map those tokens into tailwind.config.ts as the single source of truth. Do NOT hardcode colors or font sizes in components.
	4.	Fonts. Identify every font family in use. For each, either (a) self-host via next/font/local if the license allows, or (b) load the closest open-source equivalent from Google Fonts and flag the substitution in the README so I can swap it for a properly licensed copy before launch. Common Wix fonts like Avenir/Proxima/Futura should be noted explicitly.
	5.	Icons and decorative graphics. Download every icon used in “Find Your North Star,” “Our Services,” “Our Projects,” “Our Clients,” the footer social icons, and the navigation. Store them as optimized SVG where possible, PNG otherwise.
	6.	Layout. Rebuild the header (logo left, nav with multi-level dropdowns for Our Story, Services, The Feed, Resources), hero section, three-up feature cards, “From The Feed” carousel, and the multi-column footer exactly. Mobile nav should collapse to a hamburger with the same dropdown behavior.
	7.	Animations and micro-interactions. Match any scroll-triggered fades, hover states on cards, and transitions on the nav. Use Framer Motion.
	8.	Responsive behavior. Test at 360, 768, 1024, 1440, and 1920 widths and match the original’s breakpoint behavior.
